# Keyboard and accessibility

## Table shortcuts

Shortcuts work when focus is not in a text field and no modifier key is held.

| Key | Action |
|---|---|
| `/` | Focus the search box |
| `F` | Open the filter picker |
| `S` | Open the sort menu |
| `V` | Open the views menu |
| `C` | Open the columns menu |
| `←` / `→` | Previous / next page |
| `Esc` | Clear the search |
| `?` | Show the shortcuts help |

Enter on a row expands it when the table has a detail panel.

## Menus

The right-click menu uses ↑ and ↓, Home and End, Enter or Space to pick, → and ← to open and close submenus, Esc to close, and typing a letter jumps to an item. While it is open, the table shortcuts above are paused. The toolbar menus support the arrow keys, Enter and Esc.

## Charts

Each chart has `role="img"` with a label describing it, and a hidden data table with the same numbers for screen readers. When a chart filters other items, its bars and slices can be focused and picked with Enter.

## Colour

The chart palette was checked for colour-blind separation in light and dark mode, and status colours (critical, high, …) always come with a text label or legend, never colour alone.

## Announcements

Copy confirmations are shown in a toast that screen readers announce politely.
