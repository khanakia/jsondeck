# docs-content

Content for the jsondeck docs site (the site itself is built with jsondeck and reads these files). `features.json` is the feature inventory: one row per feature or component with its category, a one-sentence summary, the config keys it uses, the examples.html box that shows it, and a status (`stable`, or `check` with a `checkReason` when the docs could not confirm it from the code). `config-reference.json` lists every config key (path, TypeScript type, default, description, level) and is generated from `src/core/config.ts` by `gen-reference.mjs` (re-run it with `node docs-content/gen-reference.mjs` after changing config types; descriptions come from the JSDoc, with hand-written fallbacks inside the script where JSDoc is missing). `guides/*.md` are the guide pages, in reading order, using `:::tip`, `:::warning` and `:::steps` blocks for the site to render as components. `check-paths.mjs` checks that every config path named in `features.json` and in the guides exists in `config-reference.json`.
